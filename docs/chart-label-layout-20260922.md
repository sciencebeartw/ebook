# 分佈圖三位數標籤排版

## 範圍

只調整 eBook 聯絡簿與近期成績的共用分佈圖呈現；保留分組、人數、平均、顏色及低樣本行為。不讀寫正式學生成績、不部署 GAS／Functions。

## 原因與修正

原柱容器固定 35px、標籤寬度為其 200%，三位數含空白的區間換行後向上擠入人數。改為五等寬欄，柱子維持最多 35px；標籤獨立置於柱底下 8px、單行顯示，區間改用緊湊的連接號（例如 107–108）。手機保持五欄並減少左右空白。

## 驗證結果

隔離假資料測試 320／375／390／430／768／1280px，兩個成績頁各測單筆 107、一般 0～100 與最高 200；檢查標籤單行、相鄰標籤不重疊、零值人數與標籤不相撞、頁面無水平溢位。保留正式學生資料不動。

36 組瀏覽器檢查全部通過、pageerror 0；390px／1280px 截圖人工確認。假期卷輸入與答案流程 8 項回歸、XSS smoke、inline JavaScript parse 及 diff check 通過。測試入口：`tools/ebook_chart_labels_ui_checks.js`，僅使用隔離草稿預覽及假資料。手機 360px 以下利用卡片內側留白，保留五欄單行文字。

本輪不新增 Firebase 讀寫、監聽、Storage 或 Functions 呼叫，也不改動 GAS、試算表與正式分數。只發布 eBook 靜態前端。
