# 全同分且達 100 分的分佈圖例外

## 決策與邊界

- 一般考試維持原規則，例如最低 60、最高 80 仍顯示 60～100 五區；最高超過 100 時原本動態上限不變。
- 只有一人或全部同分，且實際分數 >=100 時，圖表改用 0～該分數五區，全部人數置於最右區。
- 不從平均、已四捨五入的區間文字或學生未審核回報猜測上下限。只接受原有 `distMin === distMax` 的有限數字及有效五區人數；矛盾／缺漏 metadata 保留原樣。
- 只修 eBook 呈現，不改 GAS 統計或 Firebase 快取，不動正式分數、平均、審核、回填及通知。沒有新增 RTDB／Storage／Functions 讀寫或 listener。舊快取只要含原有上下限即可立即套用，不必整班重新同步。

## 實作

`ebook_score_distribution.js` 是純函式；輸入不變，傳回畫面專用分組。`buildGradeListFromExams` 保留原先遺漏的 `distMin`／`distMax`；聯絡簿與近期成績都使用同一 helper。正式分數本人映射最右區／綠色，尚未回報者不高亮他人柱子。下一筆不同分數加入後自然回到原有分組。
