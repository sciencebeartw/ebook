# 段考／作業回報自行更正分數

六位老師共用的回報入口，在正式數字成績下提供「更正分數」，預填目前分數，按「儲存更正」更新同一筆。前一筆尚在背景登記時暫不允許再次送出；完成後可繼續更正，不限次數。題目已移除或不再發布仍不能送出；未知成績、公式及非數字註記不自動覆蓋。

前端帶目前正式分數與下一個 submissionRevision，Functions 重新驗證本人、班級、已發布考卷、ExamID 與分數；GAS 再核對正式格仍與 expectedScore 相同。舊頁面、並行不同分數與舊收據不能覆蓋較新結果。GAS 每版獨立 ledger 收據保存 previousScore 及 updatedAt；原回報時間、期限快照與準時／遲交保留，最後更正時間另列。既有數字沒有歷史收據時不推定先前準時，首次專區收件依當時時間判定。

修正草稿沿本人與考試版本隔離；查詢結果有舊收據時不再無條件刪除未送達的新分數草稿。

驗收採全假資料：六位 provider、七套 GAS／冠維 relay、0分與小數、連續更正、重送、老師中途改分／清空、背景同步失敗及錯誤身分。WebKit／Chrome 各13項，390及1280px無溢出與pageerror；實體LINE瀏覽器未測。正式發布僅讀回程式，不代寫正式學生分數。

成本：僅 sciencebear-admin 既有本人單卷 scoped reads、單 job transaction、Sheet 單格及既有目標考試欄同步；不新增讀取、listener、排程、Storage傳輸或跨專案流量。不發LINE，不改Rules。
